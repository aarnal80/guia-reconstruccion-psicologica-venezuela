# Aplicación web de la guía

Aplicación de lectura móvil construida con Next.js/vinext. El contenido se genera desde `../manuscrito_guia.md`.

## Desarrollo

```bash
npm install
npm run dev
```

## Comprobación

```bash
npm test
```

## GitHub Pages

La acción del repositorio ejecuta `npm run build:pages` y publica la carpeta `out`.

## Sites

`npm run build` produce el paquete de publicación de Sites.
