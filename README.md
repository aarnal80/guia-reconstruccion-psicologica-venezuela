# Guía de reconstrucción psicológica de una catástrofe

**Venezuela**

Versión impresa y online de una guía de primeros auxilios psicológicos ampliados para personas, familias y comunidades afectadas por catástrofes en Venezuela.

**Autora:** Dra. Indira Lucía Parra  
**Coautor:** Dr. Antonio José Arnal Meinhardt

## La experiencia online

La web está diseñada primero para teléfonos móviles y permite:

- acceder por necesidades concretas, sin leer el manual en orden;
- buscar cualquier palabra o pregunta;
- guardar el progreso y apartados importantes en el dispositivo;
- ajustar tamaño del texto, interlineado y modo oscuro;
- usar la guía sin conexión después de la primera visita;
- compartir apartados mediante enlaces;
- descargar el PDF completo;
- recorrer un ejercicio breve de orientación al presente.

No utiliza cuentas, publicidad ni sistemas de seguimiento.

## Publicación

El sitio se publica automáticamente en GitHub Pages desde la carpeta [`web`](web/). El manuscrito principal se encuentra en [`manuscrito_guia.md`](manuscrito_guia.md) y el contenido de la aplicación se regenera desde ese archivo.

## Aviso

Esta guía ofrece orientación general y herramientas de primeros auxilios psicológicos. No sustituye una evaluación médica, psicológica o psiquiátrica ni pretende diagnosticar a quien la lee.
